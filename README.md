# 🌴 ميامي 3D — Miami Crime 3D

لعبة مدينة أصلية ثلاثية الأبعاد للويب، بنفس نموذج **سيد العقار** و**سوبر ماريو ويب**:
التلفاز يعرض اللعبة، والهاتف هو يد التحكم، والدخول بكود غرفة — **حتى 6 لاعبين** في نفس الغرفة على شاشة واحدة.

> لعبة أصلية بالكامل: المدينة مبنية من صناديق وأسطوانات وكرات في Three.js،
> والأصوات مولّدة بـ WebAudio، بلا أي أصول أو كود أو علامات من أي لعبة أخرى
> (لا GTA ولا غيرها). مستوحاة فقط من فكرة الحلقة العامة: امشِ، اسرق سيارة،
> اهرب من الشرطة، أكمل مهاماً، واصرف فلوسك في الكراج.

## كيف تلعب

1. افتح `/tv/` على التلفاز — يظهر كود غرفة من 4 أرقام.
2. افتح `/play/` على كل هاتف وأدخل الكود والاسم.
3. اضغط **▶ ابدأ اللعب** من التلفاز (أو من أي هاتف).

| اللاعب | اللون |
|---|---|
| 1 | 🔴 أحمر |
| 2 | 🟢 أخضر |
| 3 | 🔵 أزرق |
| 4 | 🟡 أصفر |
| 5 | 🟣 بنفسجي |
| 6 | 🟠 برتقالي |

اللاعب السابع فأكثر يدخل **مشاهداً** فقط. مقعد يفرغ يُعاد استخدامه للاعب التالي.

## يد التحكم (الهاتف)

- **العصا** (يسار): الحركة / قيادة السيارة — لأعلى = أمام.
- **⬆ قفز** (أكبر زر)، **🚗 ركوب**، **👊 ضرب**، **⚡ ركض**.
- كل الأزرار على خط سفلي واحد في لوحة واحدة، بلا تمرير، وتعمل بالطول والعرض.

على لوحة مفاتيح التلفاز (للاختبار): `WASD`/الأسهم للحركة، `مسافة` قفز،
`E` ركوب، `F` ضرب، `Shift` ركض، `M` تبديل المهمة.

## قواعد اللعبة

- **على الأقدام:** امشِ واقفز واضرب. ضرب أحد المارة = نجمة مطلوبية +1.
- **السيارات:** السيارات المركونة مجانية. سرقة سيارة مرور (متحركة) = نجمة +1.
  زر 🚗 قرب سيارة للركوب، ونفس الزر للنزول.
- **الشرطة ⭐:** النجوم من 1 إلى 5، وتتلاشى ببطء إذا اختفيت عن الجريمة.
  سيارات شرطة تطارد أكثر لاعب مطلوب؛ إذا لمستك وأنت على قدميك تُقبض عليك:
  تعود لنقطة البداية وتخسر **$100** وتصفّر نجومك.
- **الفلوس 💵:** صناديق خضراء متوهجة منتشرة في المدينة (+$50)، وتظهر من جديد.
- **المهام:**
  - 📦 **توصيل:** أوصل للنقطة الصفراء = **+$600**، ثم تظهر نقطة جديدة.
  - 🏁 **سباق:** 9 نقاط خلال 120 ثانية، كل نقطة +$100، وإنهاؤها = **+$1000**.
  - 🌴 **تجول حر:** بلا مهمة.
- **الكراج 🎨** (المنطقة الصفراء جنوب-غرب المدينة): وأنت في سيارة داخله،
  زر 🚗 يغيّر لون السيارة (**$200**، يدور على 10 ألوان)، وزر 👊 يشغّل/يطفي
  النيون تحت السيارة (**$150** عند التشغيل).
- **المدينة:** 9 أحياء مسمّاة، شاطئ وبحر ورصيف خشبي، نخيل، ونهار يتحول إلى ليل
  (تضيء أعمدة الإنارة ومصابيح السيارات ليلاً). الكاميرا تتبع وسط اللاعبين،
  ومن يبتعد كثيراً عن المجموعة يعود قرب القائد.
- **الخريطة المصغرة:** أعلى الشاشة — نقاط اللاعبين والسيارات والفلوس والمهمة.

## ما تم قطعه عمداً

- **لا مسدس/إطلاق نار:** الضرب فقط. إطلاق النار كان سيعقّد التصويب على الهاتف
  ويخاطر بكسر الحلقة الأساسية، فتم الاكتفاء باللكم.
- الكاميرا تتبع وسط المجموعة (زاوية عالية) بدل كاميرا ثالث-شخص خلف كل لاعب،
  لأن 6 لاعبين لا يمكن تتبعهم بكاميرا واحدة خلف شخص واحد.

## التشغيل محلياً

```bash
npm --prefix server install
node server/server.js        # http://localhost:3000
npm --prefix server test     # اختبار الغرف والتتابع (6 هواتف + مشاهد)
```

## النشر (Render)

الملف `render.yaml` يعرّف خدمة Node مجانية:

- build: `npm --prefix server install`
- start: `node server/server.js`
- health check: `/health`

الخادم `Node + ws` فقط، بلا اعتماديات أخرى. Three.js يأتي من CDN
(`unpkg`, الإصدار المثبّت `0.160.0`)، لذا يحتاج التلفاز إنترنت.

## البنية

```
server/
  server.js          # غرف بكود + WebSocket relay (لا حالة لعب)
  package.json       # ws فقط
  test/relay.test.js # اختبار 6 لاعبين + مشاهد + إعادة المقعد
public/
  index.html         # صفحة البداية
  tv/index.html, tv.js, tv.css    # شاشة التلفاز + محاكاة Three.js
  play/index.html, play.js, play.css  # يد تحكم الهاتف
render.yaml
```
