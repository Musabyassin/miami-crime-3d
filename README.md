# 🌴 ميامي 3D — Miami Crime 3D

لعبة مدينة أصلية ثلاثية الأبعاد للويب، بنفس نموذج **سيد العقار** و**سوبر ماريو ويب**:
التلفاز يعرض اللعبة، والهاتف هو يد التحكم، والدخول بكود غرفة — **حتى 6 لاعبين** في نفس الغرفة على شاشة واحدة.

> لعبة أصلية بالكامل: المدينة مبنية من صناديق وأسطوانات وكرات في Three.js،
> والأصوات مولّدة بـ WebAudio، بلا أي أصول أو كود أو علامات من أي لعبة أخرى
> (لا GTA ولا غيرها). مستوحاة فقط من فكرة الحلقة العامة: امشِ، اسرق سيارة،
> اهرب من الشرطة، أكمل مهاماً، واصرف فلوسك في الكراج.

## كيف تلعب

1. افتح `/tv/` على التلفاز — يظهر كود غرفة من 4 أرقام.
2. افتح `/play/` على كل هاتف وأدخل الكود والاسم.
3. اضغط **▶ ابدأ اللعب** من التلفاز (أو من أي هاتف).

| اللاعب | اللون |
|---|---|
| 1 | 🔴 أحمر |
| 2 | 🟢 أخضر |
| 3 | 🔵 أزرق |
| 4 | 🟡 أصفر |
| 5 | 🟣 بنفسجي |
| 6 | 🟠 برتقالي |

اللاعب السابع فأكثر يدخل **مشاهداً** فقط. مقعد يفرغ يُعاد استخدامه للاعب التالي.

## يد التحكم (الهاتف)

- **العصا** (يسار): الحركة (نسبةً لاتجاه الكاميرا) / قيادة السيارة.
- **🔫 نار** (أحمر): إطلاق مع **تصويب تلقائي** على أقرب هدف أمامك. داخل السيارة = فرامل يد.
- **🔄 سلاح**: تبديل السلاح • **🚗 ركوب/نزول** • **👊 ضرب** • **⚡ ركض** • **⬆ قفز**.
- **اسحب المنطقة الفارغة أعلى الشاشة** لتدوير الكاميرا.

لوحة مفاتيح التلفاز (للاختبار): `WASD`/الأسهم حركة، `مسافة` قفز، `E` ركوب، `F` ضرب،
`G`/`Enter` نار، `Q` تبديل السلاح، `Shift` ركض، `Z`/`X` أو سحب الفأرة لتدوير الكاميرا،
`C` تغيير نمط الكاميرا، `M` تبديل المهمة.

## الكاميرا

- **لاعب واحد:** كاميرا **ثالث-شخص خلف اللاعب**، تتبع اتجاه السيارة وتتسع بالسرعة،
  وتقترب تلقائياً إن حجبها مبنى.
- **أكثر من لاعب:** كاميرا علوية تتبع المجموعة (تبتعد كلما تباعدوا).
- زر `C` يبدّل: تلقائي ← مجموعة ← خلف اللاعب.

## قواعد اللعبة

- **الصحة ❤ والدرع 🛡:** صناديق وردية (+35 صحة) وزرقاء (+50 درع) منتشرة في المدينة.
  عند الموت (☠️) تُنقل إلى **المستشفى** وتدفع $200.
- **الأسلحة 🔫:** تبدأ بمسدس. من **متجر السلاح** (المنطقة الحمراء): 🚗 رشاش $800 ثم بندقية $1200
  (وبعدها تعبئة ذخيرة كاملة $150)، 🔫 ذخيرة السلاح الحالي $100، 👊 درع كامل $300.
- **المطلوبية ⭐:** أذى المارة أو تدمير السيارات يرفع النجوم (يتصاعد ببطء أثناء العنف المتواصل).
  - 1–3 نجوم: سيارات شرطة تطاردك وتقبض عليك إن لمستك (-$100).
  - 3+ نجوم: **الشرطة تطلق النار**. 5 نجوم: **مروحية** إضافية.
  - ابتعد عنهم لتتراجع النجوم أسرع.
- **السيارات:** تتضرر بالاصطدام وإطلاق النار، وتحترق ثم **تنفجر** (الانفجار يؤذي من حوله).
  دهس المارة ممكن. مرور بحارات يمينية يتوقف أمام العوائق.
- **المهام:** 📦 توصيل (+$600) • 🏁 سباق 9 نقاط (+$1000) • 🎯 **مطلوبون** (اقضِ على 3 أهداف
  بعلامة حمراء، +$1500) • 🌴 تجول حر.
- **الكراج 🎨:** وأنت في سيارة داخله: 🚗 لون ($200)، 👊 نيون ($150).
- **المدينة:** 9 أحياء، شاطئ وبحر ورصيف، نخيل، ظلال، نهار/ليل (نوافذ المباني تضيء ليلاً).
  المباني داخل البلوكات فتبقى التقاطعات مفتوحة.
- **الخريطة المصغرة:** اللاعبون والسيارات والشرطة والمروحية والمناطق والمهمة.

## التشغيل محلياً

```bash
npm --prefix server install
node server/server.js        # http://localhost:3000
npm --prefix server test     # اختبار الغرف والتتابع (يحتاج الخادم يعمل)
npm --prefix server run test:logic   # اختبار منطق اللعبة دون متصفح (Three.js وهمي)
```

## النشر (Render)

الملف `render.yaml` يعرّف خدمة Node مجانية:

- build: `npm --prefix server install`
- start: `node server/server.js`
- health check: `/health`

الخادم `Node + ws` فقط، بلا اعتماديات أخرى. Three.js يأتي من CDN
(`unpkg`, الإصدار المثبّت `0.160.0`)، لذا يحتاج التلفاز إنترنت.

## البنية

```
server/
  server.js          # غرف بكود + WebSocket relay (لا حالة لعب)
  package.json       # ws فقط
  test/relay.test.js # اختبار 6 لاعبين + مشاهد + إعادة المقعد
  test/logic/        # اختبار منطق tv.js دون متصفح (قتال، شرطة، مهام، مستشفى…)
public/
  index.html         # صفحة البداية
  tv/index.html, tv.js, tv.css    # شاشة التلفاز + محاكاة Three.js
  play/index.html, play.js, play.css  # يد تحكم الهاتف
render.yaml
```
